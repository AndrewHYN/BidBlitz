# BidBlitz\n\n**List it. Start the blitz. Get your price.**\n\nBidBlitz is a fast, real-time marketplace where people sell items through competitive live bidding.\n\n## MVP\n\nThe first release focuses on one thing: turning an item into a completed sale quickly.\n\nSeller:\n- Create an auction in a few steps\n- Upload clear item photos\n- Set starting bid, bid increment, duration, condition, and location\n- Publish and monitor the auction\n- See the winning bid and transaction status\n\nBuyer:\n- Discover live auctions\n- See current bid and authoritative time remaining\n- Place bids in real time\n- Receive outbid/win updates\n- Review completed purchases\n\nMarketplace:\n- Live auction states\n- Concurrency-safe bidding\n- Server/database-authoritative auction closing\n- Anti-sniping extension\n- Seller/buyer reputation foundations\n- Platform fee calculation\n- Transaction history\n\n## Product direction\n\nDo not build this like a classifieds clone.\n\nBidBlitz should feel like a combination of modern commerce, a live sporting event, and a clean auction room.\n\nThe user should understand the next action within seconds.\n\n## Planned stack\n\nNext.js App Router + TypeScript + Tailwind CSS v4 + shadcn/ui + Supabase Postgres/Auth/Storage/Realtime + Zod + Playwright + Vercel.\n\n## Development\n\nRead AGENTS.md before changing the project.\n\nThe detailed MVP contract is in docs/MVP_SPEC.md.\n
